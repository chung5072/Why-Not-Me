# 나는 왜 안 써? (WhyNotMe)

> 폰에 깔려는 있는데 요즘 안 여는 앱이, 가끔 화면에 끼어들어 삐짐.

다른 앱 사용 중 화면 위로 요즘 안 쓰는 앱의 아이콘이 튀어나와 몇 번 튀어다니다 화면
가장자리에 붙어서 말풍선으로 한마디 남기고 사라지는, 실용성 없는 장난감 안드로이드 앱.

## 기획 의도

- 사용자별로 가장 안 쓰는 앱을 뽑아, 그 앱이 스스로 "나는 왜 안 써?"라고 말을 거는 컨셉
- 시스템 앱이 아닌 독립 실행 앱

## 동작 방식

1. **감지** — `UsageStatsManager`로 앱별 사용 빈도 확인(최근 30일 기준)
2. **판단** — 앱 전환마다 설정된 빈도(가끔 5% / 보통 12% / 자주 25%)와 쿨다운
   (1시간 / 30분 / 10분) 확인 후 등장 여부 결정
3. **등장** — 판단 통과 시 1~2초 지연(자연스러운 "끼어듦" 연출) 후 캐릭터 아이콘이 화면
   위를 튀어다니다 좌우 가장자리에 도킹, 말풍선으로 문구 표시, 같은 가장자리로 슬라이딩
   퇴장
4. **반응** — 말풍선 탭 시 앱 열기 / 오늘만 그만 묻기 / 후보에서 완전 제외 중 선택 가능

## 주요 기능

- 안 쓰는 앱 자동 감지 + 무작위 등장 애니메이션
- 은행/페이/인증서 앱 자동 감지 → 오버레이 표시 제외(안전 목적)
- "후보에서 제외" 옵션 — 보안 목적으로 설치만 해두고 일부러 안 쓰는 앱을 후보에서 배제
- 오늘 그만 묻기 / 1시간 쉬기 / 전체 켜고 끄기
- 삐진 문구 직접 추가·수정
- 다크모드 전용 UI("삐짐" 컨셉의 진분홍 액센트)

## 필요 권한

| 권한 | 용도 |
|---|---|
| 사용정보 접근 | 앱별 사용 빈도 확인 전용. 앱 내 활동 내용은 확인 안 함 |
| 다른 앱 위에 표시 | 캐릭터 아이콘·말풍선을 다른 앱 화면 위에 렌더링하기 위해 필요 |
| 알림 | 감시 상태 상주 알림 표시용(Android 13+) |
| 배터리 최적화 제외 | 백그라운드 감지 중단 방지용, 선택 사항 |

인터넷 권한 없음 — 수집한 사용 정보는 기기 밖으로 전송되지 않음.

## 기술 스택

- Kotlin, Jetpack Compose + Material3(다크모드 고정)
- 오버레이(캐릭터+말풍선) 부분만 전통 Android View + `android.animation` API 사용
  — `WindowManager` 오버레이 창은 Activity 비종속이라 ComposeView 적용 시 별도 Lifecycle
  연결 필요, 해당 이유로 이 부분만 View로 구현
- 최소 SDK 29(Android 10)
- SharedPreferences 기반 로컬 저장(서버 없음, 외부 전송 없음)

## 빌드

```bash
git clone https://github.com/chung5072/whynotme.git
cd whynotme
./gradlew assembleDebug
```

Android Studio에서 프로젝트 오픈 후 Run으로도 실행 가능.
